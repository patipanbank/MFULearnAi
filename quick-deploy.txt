🚀 QUICK DEPLOYMENT - Copy & Paste Commands
=======================================================

วิธีใช้: Copy คำสั่งทั้งหมดด้านล่างนี้ไปรันใน SSH terminal

=======================================================
STEP 1: SSH เข้า Server
=======================================================
ssh mfulearnai@10.1.44.204

=======================================================
STEP 2: Run Deployment (Copy ทั้งหมด)
=======================================================

cd MFULearnAi && \
echo "📥 Pulling latest code..." && \
git fetch origin kubernetes && \
git reset --hard origin/kubernetes && \
echo "✅ Code updated" && \
echo "" && \
echo "📦 Installing dependencies..." && \
cd k8s/services/agent-service && \
npm install --production && \
echo "✅ Dependencies installed" && \
echo "" && \
echo "🔨 Building TypeScript..." && \
npm run build && \
echo "✅ Build completed" && \
echo "" && \
echo "🔄 Restarting agent-service..." && \
cd ~/MFULearnAi && \
docker-compose stop agent-service && \
docker-compose rm -f agent-service && \
docker-compose up -d agent-service && \
echo "✅ Service restarted" && \
echo "" && \
echo "⏳ Waiting for service to start..." && \
sleep 10 && \
echo "" && \
echo "🔍 Checking status..." && \
docker ps | grep agent-service && \
echo "" && \
echo "✅ Deployment completed!" && \
echo "" && \
echo "📋 To view logs, run: docker logs -f agent-service"
